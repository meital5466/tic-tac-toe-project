# Tic Tac Toe 🎮

A two-player Tic Tac Toe game that runs in the terminal, written in Python.
Built as a project for the Python course at Success College.

## Features
- Displays the game board after every move
- Gets the player's choice (row and column)
- Checks for invalid input (out of range, taken positions, non-numbers)
- Detects a win (rows, columns, diagonals) or a tie

## How to Run
1. Make sure Python is installed
2. Download `tic_tac_toe.py`
3. Run in the terminal:
   python tic_tac_toe.py

## How to Play
- Player X starts, then players take turns
- Enter a row number (0-2) and a column number (0-2)
- The first player to get 3 in a row wins!
